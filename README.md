<h2 id="english-version">🇺🇸 English Description</h2>

**Mamad Proxy** is an open-source, beautifully designed Android application to easily find, test, and manage the fastest proxies for Telegram. The UI relies on a stunning **Glassmorphic** design with liquid backgrounds and full theming capabilities.

### ✨ Key Features
- **Smart Ping Tester:** Ultra-fast background ping check for all proxy servers.
- **Glassmorphism UI:** Seamless, modern, and fluid interfaces (Jetpack Compose).
- **Adaptive Theming:** Flawless Light & Dark Mode functionality.
- **Bi-directional Multilingual Support:** Out-of-the-box support for LTR (English) & RTL (Persian) based on custom app locales.

### 🛠️ Tech Stack & Architecture
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose & Material 3
- **Architecture Pattern:** MVVM
- **Navigation:** Compose Navigation

<h2 id="persian-version">🇮🇷 توضیحات فارسی</h2>

پروژه **Mamad Proxy** یک اپلیکیشن اپن‌سورس و بسیار زیبا برای پینگ‌گرفتن، مدیریت و یافتن بهترین پروکسی‌ها (کانفیگ‌های تلگرام) در اندروید است. این برنامه با رابط کاربری متفاوتِ «شیشه‌ای (Glassmorphic)» تجربه‌ای فوق‌العاده نرم و مدرن به کاربر می‌دهد.

### ✨ امکانات اصلی
- **تست سریع پینگ:** بررسی و مرتب‌سازی پروکسی‌ها براساس میزان تاخیر (Ping).
- **رابط کاربری چشم‌نواز:** طراحی کاملا مدرن و شیشه‌ای پیاده‌شده با کامپوز.
- **دارک-مد یکپارچه:** تغییر رنگ و افکت‌ها در حالت روز و شب به‌صورت خودکار و بدون افت فریم.
- **دوزبانه بودن با رعایت اصول RTL:** سوئیچ روان بین فارسی و انگلیسی به‌صورت پویا از داخل خود تنظیمات اپلیکیشن بدون به هم ریختگی ابعاد.

### 🛠 تکنولوژی‌های استفاده‌شده
- زبان برنامه‌نویسی **کاتلین (Kotlin)**
- طراحی رابط کاربری تماماً با **جت‌پک کامپوز (Jetpack Compose)**
- معماری استاندارد **MVVM**
